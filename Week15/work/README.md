## Domain Explanation

This project implements a **Retrieval-Augmented Generation (RAG) conversational assistant** for **ShopEase**, a fictional e-commerce platform. The chatbot answers customer questions about returns, shipping, warranties, payments, and membership programs by retrieving relevant content from indexed policy documents.

The E-Commerce domain was chosen because:
- Policy documents are well-structured and factual
- Follow-up questions are natural ("Does this apply to electronics?", "What about international orders?")
- Clear scenarios for hallucination testing (out-of-scope questions)
- Practical, real-world use case for customer support automation

## Setup & Usage Instructions

### Prerequisites
- Python 3.10+
- OpenAI API key (or Vocareum proxy key)

### Step 1: Install Dependencies
```bash
pip install -r requirements.txt
```

### Step 2: Configure API Key
Edit `.env` file:
```
OPENAI_API_KEY=your-api-key-here
OPENAI_API_BASE=https://openai.vocareum.com/v1  # if using Vocareum
MODEL=gpt-4o-mini
```

### Step 3: Ingest Documents
```bash
python ingest.py
```
This loads all documents, splits them into chunks, generates embeddings, and saves the FAISS index.

### Step 4: Run the Chatbot

**Option A: Interactive CLI**
```bash
python chatbot.py
```

**Option B: Demo mode (preset queries for evaluation)**
```bash
python chatbot.py --demo
```

**Option C: Streamlit Web UI (bonus)**
```bash
streamlit run app.py
```

## Key Design Decisions

1. **Chunk Size (800 chars, 150 overlap)**: Policy documents have clear section boundaries. 800 chars captures complete subsections without mixing unrelated content.

2. **Top-K = 4**: Retrieves enough context for comprehensive answers while staying within token limits.

3. **ConversationalRetrievalChain**: Uses a question condenser to rephrase follow-up questions as standalone queries, enabling accurate retrieval for multi-turn conversations.

4. **Strict System Prompt**: Explicitly instructs the LLM to only use retrieved context and refuse when information is missing — the core hallucination prevention mechanism.

5. **Source Citations**: Every response includes the source document name, enabling users to verify the information.
