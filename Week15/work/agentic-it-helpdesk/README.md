# Agentic IT Helpdesk Triage + Guided Resolution (Weeks 1–5)

This repository is a step-by-step, industry-style build of an agentic application:
- **Week 1**: Spec freeze (use case, states, tool schemas, prompts, tests)
- **Week 2**: Implement tools locally + unit tests + local KB/policy data
- **Week 3**: Single agent loop (Perceive→Plan→Act→Validate + HITL) + CLI + replay + JSONL logs
- **Week 4**: Mini-production upgrades (config-driven, latency/metrics logs, resilience)
- **Week 5**: Memory (SQLite user + case memory) + selective context injection (MCP-lite)

See **RUNBOOK.md** for how to set up and run everything.
